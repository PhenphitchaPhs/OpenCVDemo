# ระบบตรวจจับอารมณ์บนใบหน้า (Facial Emotion Detection)

เว็บที่ตรวจจับใบหน้าจากกล้อง แล้วทำนายอารมณ์ของผู้ใช้แบบเรียลไทม์
ทำงานบนเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม
โมเดลจำแนกอารมณ์ได้ 7 แบบ ได้แก่ โกรธ (angry), รังเกียจ (disgust),
กลัว (fear), มีความสุข (happy), เศร้า (sad), ประหลาดใจ (surprise)
และเฉย ๆ (neutral)

## หลักการทำงาน
- ตรวจจับใบหน้า: OpenCV.js ร่วมกับ Haar Cascade
- จำแนกอารมณ์: โมเดล YOLO11 (ไฟล์ ONNX)

## การเทรนโมเดล
- ชุดข้อมูล: FER2013 (จาก Kaggle)
- โมเดล: YOLO11n-cls (Ultralytics)
- เทรนและทดสอบใน Google Colab โดยใช้โค้ดตั้งต้นจากในชั้นเรียน
  และปรับค่าการเทรนเอง (เช่น จำนวน epochs และขนาดภาพ) เพื่อทดลอง
  หาผลลัพธ์ที่ดีขึ้น
- Export โมเดลเป็นไฟล์ ONNX เพื่อนำมารันบนเว็บผ่าน OpenCV.js

## เทคโนโลยีที่ใช้
- HTML, JavaScript, OpenCV.js
- Python, Ultralytics YOLO (สำหรับเทรนโมเดล)
- Deploy: Vercel
